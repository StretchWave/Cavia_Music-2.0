## 3. Rust Ecosystem Security Review

### 3.1 Core Crates Audit
| Component | Version | Advisory Assessment | Exposure Assessment |
| :--- | :--- | :--- | :--- |
| **`tauri`** | 2.12.3 | Up to date with Tauri 2.x patch line. | Safe. Commands strictly mapped to IPC handlers. |
| **`sqlx`** | 0.9.x | No active advisories. | Safe. SQL queries use parameterized binds; zero string interpolation. |
| **`reqwest`** | 0.12.x | Built with `rustls-tls` (`default-features = false`). | Safe. Eliminates OpenSSL dynamic linking vulnerabilities. |
| **`lofty`** | 0.25.x | Pure Rust audio tag parser. Memory safe. | Safe. Untrusted audio files parsed within Rust memory safety boundaries. |
| **`rodio`** | 0.23.x | Pure Rust CPAL/Symphonia playback pipeline. | Safe. No dynamic C runtime execution. |
| **`keyring`** | 4.2.x | Native OS credential manager wrapper. | Safe. Refresh tokens stored in platform credential stores. |

### 3.2 Mitigation of C Dependency Hazards
Unlike traditional music players that link dynamic C libraries (such as `libmpv`, `ffmpeg`, or `libavcodec`), Cavia's primary audio pipeline uses zero-dependency native Rust decoders (`rodio`, `symphonia`). This eliminates buffer overflow vulnerabilities and native memory corruption attack vectors from malformed audio streams.
