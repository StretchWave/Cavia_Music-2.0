## 3. Privacy & Data Handling Summary

- **Zero Telemetry / Analytics**: A full current binary and dependency audit was not performed in this work session.
- **Audio Privacy**: Audio files and embedded picture bytes **never leave the user's computer**.
- **External Data Flows**:
  1. `https://lrclib.net/api/get`: HTTPS GET sending public track title, artist, album, and duration only. Zero filenames or local paths sent.
  2. Optional Supabase Sync: Authenticated HTTPS sending user ID, track content hashes, and playlist definitions only.
- **Local Storage Paths**:
  - Windows: `%APPDATA%\com.stretchwave.cavia\`
  - Database: `cavia-library.sqlite3` with Write-Ahead Logging (WAL).
  - Artwork: `artworks/<hash>.<ext>` with SHA-256 content deduplication.
- **Credential Storage**: Windows Credential Manager is used on Windows. macOS runtime storage has not been exercised. Mobile token operations fail closed because native Android/iOS secure-store adapters are not integrated; no fallback to SQLite is permitted.
