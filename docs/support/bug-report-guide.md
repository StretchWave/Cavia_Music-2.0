# Cavia Music — User Support & Bug Reporting Guide

Thank you for helping improve Cavia Music. Before filing an issue, please review this guide to ensure your report is actionable and protects your personal privacy.

---

## 1. Redaction & Privacy Guidelines

When submitting an issue or log excerpt, **NEVER post or upload**:
- Your cloud sync account password or authentication tokens.
- Private music audio files or copyrighted recordings.
- Full local directory paths if they contain sensitive personal names.
- Raw database files containing personal listening history.

All error messages in Cavia Music are formatted to sanitize tokens and credentials automatically.

---

## 2. Useful Information to Include

When reporting a defect, please provide:
1. **Cavia Version**: Found in **Settings → About** (e.g., `2.0.0`).
2. **Operating System**: (e.g., Windows 11 Home 24H2, macOS Sonoma 14.5, Android 14).
3. **Audio Output Device**: (e.g., Realtek High Definition Audio, USB DAC, Bluetooth Headphones).
4. **Audio Format**: (e.g., 24-bit 96kHz FLAC, 320kbps MP3).
5. **Exact Error Message**: Copy the text from the notification toast or Settings screen.
6. **Reproduction Steps**: A concise list of actions that triggers the issue.
