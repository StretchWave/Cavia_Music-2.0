# Platform support plan

| Capability | Windows | macOS | Android | iOS |
|---|---|---|---|---|
| Shared React UI | Planned | Planned | Planned | Planned |
| Tauri shell | Planned | Planned | Planned | Planned |
| SQLite local library | Foundation present; build unverified | Foundation present; build unverified | Foundation present; build unverified | Foundation present; build unverified |
| Native file picking | Dialog plugin configured | Dialog plugin configured | URI staging still required | sandbox/security-scope staging still required |
| Metadata extraction | Planned | Planned | Planned after URI staging | Planned after sandbox staging |
| Local audio playback | Desktop backend not wired | Desktop backend not wired | Media3 adapter not wired | AVPlayer adapter not wired |
| Network audio playback | Not yet verified | Not yet verified | Not yet verified | Not yet verified |
| Background playback | Not implemented | Not implemented | Not implemented | Not implemented |
| System media controls | Not implemented | Not implemented | Not implemented | Not implemented |

This is a roadmap, not a compatibility claim. Update this table only after testing real devices and clean desktop installations.
