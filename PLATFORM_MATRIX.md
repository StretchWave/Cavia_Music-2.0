# Platform support matrix

Legend: **Verified** means exercised in this remediation on the stated platform. **Implemented, runtime-unverified** means code exists and compiles for that target but its user-facing behavior was not fully exercised. **Not integrated** means an honest stub returns `BackendUnavailable` and reports `not_integrated`. **Unsupported** means no implementation and no claim.

**Verification scope:** This pass targets Windows 11 desktop and Android 16 x86_64 emulator. Windows UI and live YouTube Music search were inspected at 1440×900; a Windows host smoke test also resolved and cached a real provider result and decoded its audio. Android checks included app launch, private SQLite creation, SAF folder selection/staging, a WAV scan, local Media3 playback, live YouTube Music search and playback, and active MediaSession state. Android background playback and physical device output were not checked. macOS and iOS are outside this pass. Windows device-disconnect recovery is implemented but has not been exercised by physically disconnecting and restoring an output device.
